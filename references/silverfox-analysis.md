# 银狐相关证据的研判原则

本指南整理了原版 Skill 中适合离线使用的分析原则，以及公开研究中反复出现的行为组合。它是**调查线索**，不是当前 AVTool 包的事实，也不表示某个文件、域名或进程名始终具有恶意性。不同研究报告可能描述不同活动，不得将多条链的文件、任务和 C2 拼成一份虚构样本。

## 先按来源独立审查

开始跨来源关联前，先逐类确认数量、时间范围、字段质量和异常分布，避免只按已知 IOC 搜索而漏掉新变种。大表可使用本来源自身的聚合、稳定分页和条件查询；记录实际审查范围，不能把聚合统计冒充逐条人工复核。

| 来源 | 首轮应看什么 | 常见误判 |
|---|---|---|
| 浏览器历史与下载 | 原始 URL、跳转或来源页、下载状态、路径、时间、重复下载 | 访问可疑页面不等于已下载；`Succeeded` 不等于文件已执行 |
| LastActivity、Recent、Prefetch、Amcache | 精确路径、动作类型、原始时间、历史运行痕迹 | Recent 的打开记录不等于压缩包已解压；Prefetch 引用路径不证明同名扫描文件已运行 |
| 服务、计划任务、Run 项 | 目标路径、命令、启用状态、运行主体、触发条件 | 正常任务名称可被仿冒；仅有创建项不证明它已触发 |
| 进程与模块 | 映像路径、命令行、签名状态、父进程、同目录 DLL | 系统进程名不证明进程是真正系统文件；PID 可能复用 |
| 网络、DNS 与 SRUM | 连接状态、端点、端口、进程身份、时间与解析质量 | `SYN-SENT` 不是已建立的会话；SRUM 时间异常时不能直接作归因 |
| 病毒规则与样本分析 | 规则特异性、文件路径、哈希、重复命中 | 多条启发式命中同一哈希，不是多份独立恶意证据 |
| 内存命中 | 规则定义、命中区域、转储大小、重复地址、进程身份 | 宽泛字符串或重复命中不等于家族确认；未读转储不能声称完成逆向 |
| USN、任务等原生工件 | 与具体对象关联的文件变化、路径和时间 | 原生解析缺字段或时间异常时，不能补造确定时间线 |

对每类来源记录“已采集但无相关发现”“未采集”“解析不完整”三种不同状态。一个来源为空时，可以继续分析其他来源，但不能写“该行为不存在”。

## 再建立跨来源证据链

优先核对同一主机、相近时间窗内的连续环节：**投递来源 → 宿主或侧载文件 → 执行与代码加载 → 持久化或防护改动 → 实际网络连接**。与样本和时间窗相符的通信证据，比孤立的滚动 IOC 强；缺少的环节应在报告中明确写出。

值得优先检查的组合包括：签名宿主从同目录加载来源异常的 DLL；同目录又有加密数据、图片或日志载荷；新驱动服务出现后安全进程终止；新计划任务或 Run 项指向同一路径，并伴随安全防护配置变动。任务应核对动作、运行主体、间隔及创建时间；服务应核对 `ImagePath`、实际文件哈希与签名。`taskhostw.exe`、`svchost.exe`、`UserAccountBroker.exe`、`tracerpt.exe` 等正常进程名，只有结合异常线程、模块或网络上下文才可能支持注入判断。

单独的 `libcef.dll`、`thumbs.db`、云服务商 IP、未签名规则、内存字符串或 YARA 标签、公开 IOC，均先作线索。升级风险前核对路径、哈希、签名链、父子进程或模块加载关系及时间。存在签名块但哈希校验失败，不等于有效签名。已报道的驱动和远控组件可被其他家族复用，历史 IOC 的当前用途也可能变化。不能仅凭进程名出现在安全软件名单中就自动压制命中或网络活动，应先验证可执行文件身份。

将**观察到的行为**与**家族或操作者归因**分开。ValleyRAT、Winos、Gh0st、商业远程管理组件和 BYOVD 驱动均可能跨活动复用。一次网络尝试不证明握手成功或数据外传；从可疑站点拿到正常安装包，也不能单独证明站点安全，因为有研究记录按请求上下文分发不同文件。

原版 Skill 的 AVTool 采集器例外只能在相关采集批次中核对了工具文件身份和哈希后使用。不能因文件名相近，便排除整个目录或其他样本。若存在浏览器历史，可按“访问来源 → 下载 → 本地文件 → 执行”逐环节关联；若只有下载记录，就从下载开始分析，并标明缺失的来源或执行证据。

跨来源关联尽量使用同一文件的哈希和规范化完整路径，并核对批次、时间顺序和进程身份。只靠 PID、文件名、大小、相似目录或相隔很久的事件属于弱关联。内存规则、异常持久化和网络端点也可能各属不同链；要先寻找直接相连的对象，再决定是否归并。

在报告中分别写明对象风险、主机调查优先级与家族归因信心。独立的恶意行为组合可以提高处置优先级；原始扫描器的 `HIGH` 标签、无签名、高熵、宽泛 API 特征或同哈希重复命中不能单独升级。处置建议应对应尚缺的文件、日志或会话证据，并说明新证据将如何改变判断。
